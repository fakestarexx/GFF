# GFF

GFF Latin is a Latin-script typeface based on the GFF font developed for Garena Free Fire, created in collaboration with a professional type designer.
This repository provides web-ready font files and CSS `@font-face` definitions for simple integration.


## Font Details

- **Font Family:** GFF Starexx  
- **Script:** Latin  
- **Formats:** WOFF2, WOFF, TTF  
- **Weights:**  
  - 100 (**Thin**) 400 (**Regular**) 500 (**Medium**) 700 (**Bold**)

import 'https://cdn.jsdelivr.net/gh/fakestarexx/GFF/font.css';
